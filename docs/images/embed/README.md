# Screenshots for the Embedding Guide (optional upgrade)

`docs/EMBED_GUIDE.md` is **already complete** — it uses inline ASCII diagrams of
every panel, so it reads fine with no images. These PNGs are an *optional*
upgrade: capture them and the guide looks even nicer (replace the matching
diagram with `![caption](images/embed/NN-name.png)` when you add one).

Capture each from the **admin console → Integrations → your widget** cockpit
(the panel that shows EMBED ID / PUBLIC KEY / SECRET / ENDPOINT / DROP-IN
SNIPPET / FULL PHP CODE).

| File | What to capture |
|------|-----------------|
| `01-cockpit-overview.png` | The whole widget cockpit (header row: store name, `public`, origins, Live, ON toggle, copy/download/preview/settings). |
| `02-keys.png` | The **KEYS** panel — EMBED ID, PUBLIC KEY, SECRET (hidden), ENDPOINT. |
| `03-config.png` | The **CONFIG** panel — SCOPE / ROLE / RATE / AUTH / STATUS / STYLE. |
| `04-snippet.png` | The **DROP-IN SNIPPET** box + its `copy` button. |
| `05-php-code.png` | The **FULL PHP CODE** tabs (`widget-embed.php` / `CityAgentClient.php`) + `show` button. |
| `06-access-allow.png` | The **Access** tab — allow-list + "Sites trying to embed" with the **Allow** button. |
| `07-widget-live.png` | The result on a test page — the coral robot launcher bottom-right. |
| `08-widget-open.png` | The widget open — header robot, greeting, suggested cards. |

Recommended width: ~1200px. PNG. Keep them light (< 300 KB each).
